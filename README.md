One line, at most 200 characters: the funniest excuse a robot vacuum gives for missing a spot. This entry's line, in deadpan robot voice:

> The spot has been there for three days, so under my firmware it is now a resident, and residents do not get vacuumed.

Built for the [make.fun bounty "The Vacuum's Alibi"](https://make.fun/bounty/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7).

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

`main.ts` (Node stdlib only) copies `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
